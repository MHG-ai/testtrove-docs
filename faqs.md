# FAQs

## I cannot see Admin.

Your role may not have admin permission. Contact an administrator.

## I cannot create or edit an item.

Your role may not include the required action permission.

## AI generation did not run for a release.

Confirm that a release scope file was uploaded and Generate Plans (AI) was selected before saving the release.

## AI-generated test cases were not created.

Check that at least one case was selected. If folder creation fails, verify project access and folder permissions.

## A report has missing data.

Confirm that the related plan, release, run, build, or environment has data before generating the report.

## Session expired.

Sign in again. If the issue continues, contact an administrator.

## Why are some buttons missing?

Buttons are permission-based. If an action is missing, your role may not include that permission.

## What should I add to AI Context?

Add product behavior, testing standards, domain rules, and project-specific expectations that AI should consider when generating plans or cases.

## Should I create all AI-generated plans?

No. Review the AI plan suggestions and select only the plans that match the release scope.

## Should I create all AI-generated test cases?

No. Review the suggested cases, edit where needed, and create only the useful cases.

## What happens if an AI case references a folder that does not exist?

TestTrove checks for the folder first. If it does not exist, TestTrove creates the folder before creating the test case.
