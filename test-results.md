# Test Results

Test results capture the outcome of test execution.

## View Results

1. Open a project.
2. Go to TestPlans.
3. Open a plan.
4. Open a run.
5. Review the test result list.

## Record Results

During execution, update each test case with its result status.

Common result statuses may include:

- Passed
- Failed
- Blocked
- Not Tested
- Not Applicable

The exact list depends on project configuration.

## Result Details

Open a result detail page to view:

- Test case details
- Execution status
- Logs
- Comments
- Bug or issue information when available

## Release Readiness

Result data contributes to release insights and readiness views. Make sure results are recorded accurately before reviewing release health.

## Best Practices

- Add clear comments for failed and blocked results.
- Link issue details when failures need external tracking.
- Keep execution logs concise but useful.
- Review result trends before release decisions.
