# Test Runs

Test runs are execution instances for a test plan.

## Open Test Runs

1. Open a project.
2. Go to TestPlans.
3. Open a test plan.
4. View the runs associated with that plan.

## Create or Edit Runs

Runs may include:

- Name
- Assignee
- Description
- Related plan
- Execution context

Use the run modal to create or update run details.

## Execute a Run

1. Open the run.
2. Review the test cases assigned to the plan.
3. Execute each case.
4. Record the result status.
5. Add logs, comments, or issue details where needed.

## Best Practices

- Create separate runs for separate cycles, builds, or environments.
- Assign a clear owner for each run.
- Record comments for failures and blockers.
- Keep run naming consistent across release cycles.
