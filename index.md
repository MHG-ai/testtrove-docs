# TestTrove Documentation

Welcome to the TestTrove user documentation.

TestTrove is a test management workspace for organizing projects, releases, test cases, test plans, test runs, execution results, reports, and AI-assisted QA workflows.

## Who This Guide Is For

This guide is for QA engineers, test leads, project owners, administrators, and stakeholders who use TestTrove to plan, execute, and report testing activity.

## Product Structure

TestTrove is project-centered. After signing in, users land on the Projects page. Opening a project gives access to the project workspace:

- Overview
- Releases
- TestCases
- TestPlans
- Test Env
- Reports
- UseCases
- AI Context

## Recommended Workflow

1. Create a project.
2. Add AI Context for project-specific testing rules.
3. Create a release and upload release scope.
4. Generate AI release insights.
5. Review and create selected AI test cases.
6. Review and create selected AI test plans.
7. Add or refine manual test cases.
8. Assign test cases to plans.
9. Create test runs.
10. Execute tests and record results.
11. Review release insights and readiness.
12. Create and share reports.
