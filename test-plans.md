# Test Plans

TestPlans define what should be executed for a release or test point.

## Create a Test Plan

1. Open a project.
2. Go to TestPlans.
3. Select Add Plan.
4. Enter Name.
5. Select Release.
6. Enter Test Point.
7. Select Assignee.
8. Enter Scope.
9. Optionally enter Description.
10. Select Save.

## Edit a Test Plan

1. Use the edit icon on a plan row.
2. Update plan details.
3. Save.

## Select Test Cases for a Plan

1. Select the Select Cases action for a plan.
2. Use the table checkbox selection to choose cases.
3. Select Save.

## AI Release Plan Creation

AI release insights can suggest test plans from a release scope document.

1. Create a release with Generate Plans (AI) selected.
2. Review generated AI release insights.
3. Select Create Release Plan.
4. Review the AI plan suggestions in the Review AI Test Plans modal.
5. Select only the plans you want to create.
6. Edit plan details such as Plan Name, Test Point, Scope, and Description.
7. Confirm Create Selected Plans.

The current user is used as the plan assignee.

## Best Practices

- Create plans around release scope, risk areas, or execution phases.
- Assign ownership before execution starts.
- Keep Scope specific enough for execution teams.
- Use Select Cases to keep each plan focused.
