# Getting Started

## Main Navigation

The left sidebar contains the main navigation.

- Dashboards: View and manage dashboards.
- Projects: View all projects and enter project workspaces.
- Admin: Available only for users with admin permission.

When you open a project, the sidebar changes to project navigation.

- Overview
- Releases
- TestCases
- TestPlans
- Test Env
- Reports
- UseCases
- AI Context

The sidebar can be collapsed or expanded using the hover trigger near the top edge.

## First-Time Setup Flow

For a new team or project, use this flow:

1. Sign in to TestTrove.
2. Open Projects.
3. Create a project.
4. Open the project.
5. Add project-specific AI Context.
6. Add releases and scope.
7. Create or generate test cases.
8. Create test plans.
9. Create runs and record results.
10. Generate reports.

## Dashboards

Dashboards provide project and testing visibility.

### Create a Dashboard

1. Go to Dashboards.
2. Select Create Dashboard.
3. Enter Name.
4. Enter Description.
5. Select Type.
6. Select users if dashboard access is shared.
7. Save.

Dashboards can include widgets for project and execution insights.

## User Profile

Use the profile menu to open your user profile. You can review profile details and change your password.

## Permissions

Some buttons or pages appear only when the user has the required permission.

Examples:

- Create Release
- Update Release
- Create Test Plan
- Update Test Plan
- Delete Test Plan
- Admin access

If an expected action is missing, contact an administrator to review your role and permissions.

## Admin

Admin options are visible only to users with admin permissions.

### Users

Use Users to manage users, roles, groups, and user actions.

### Project Settings

Use Project Settings to create or update projects and configure project access.

### System Config

Use System Config to manage shared system settings, such as configurable statuses, fields, and project-level options.

### Integrations

Use Integrations to configure external systems such as issue, build, or code integrations.

### Backup

Use Backup to download a backup or configure a backup schedule.
