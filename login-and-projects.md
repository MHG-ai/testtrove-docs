# Login and Projects

## Standard Sign In

1. Open your tenant TestTrove URL.
2. Enter your login credentials.
3. Select Sign In.

After login, TestTrove opens the Projects page.

## First-Time Sign In

First-time users may be sent to the First Time Sign In screen.

1. Confirm the email address shown on screen.
2. Enter a username.
3. Enter and confirm a password.
4. Select Create Account.

After the account is created, TestTrove opens the Projects page and shows a getting-started guide.

## Password Recovery

Use Forgot Password from the login screen to request a reset link. Use the reset screen to set a new password.

## Projects Page

The Projects page is the home page.

### Create a Project

1. Go to Projects.
2. Select Add Project.
3. Enter Project Name.
4. Enter Description.
5. Select Create.

### Open a Project

Select the project name to open the project overview.

### Quick Links

Each project row includes quick links for:

- Overview
- Releases
- Test Cases
- Test Plans
- Test Environments
- Reports

### Getting Started Guide

New users see a getting-started panel and guided tour. Select Show Guide to replay it.

The recommended project setup flow is:

1. Create a project.
2. Add release scope.
3. Build test cases.
4. Create plans, run tests, and report results.

## Project Overview

The Overview page summarizes project-level activity and metrics. Use it as the starting point for checking project health before moving into releases, test cases, and plans.

## Test Environments

Use Test Env to define the environments used for execution.

### Add a Test Environment

1. Go to Test Env.
2. Select Add Test Environment.
3. Enter Name.
4. Select Type.
5. Enter OS.
6. Enter User.
7. Add Password or Key File details when applicable.
8. Add Description.
9. Save.

## UseCases

UseCases describe functional or business scenarios and can be linked with test cases.

### Create a UseCase

1. Go to UseCases.
2. Select Add UseCase.
3. Enter Title and Summary.
4. Add Business Context.
5. Add Assumptions, Constraints, Preconditions, and Postconditions.
6. Optionally select related test cases.
7. Save.
